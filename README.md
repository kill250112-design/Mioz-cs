# CS2 — Кейсы

Мобильное демо-приложение на Vite: открытие кейсов с анимированной рулеткой, локальный баланс и инвентарь.

> Важно: цены демонстрационные, не являются live-котировками Steam/CSFloat. Баланс, выпадения и продажа работают локально в браузере. Реальные платежи, аккаунты и серверная проверка не реализованы.

## Запуск
Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Production-сборка: `npm run build`.

## GitHub Pages
Workflow в `.github/workflows/deploy.yml` автоматически собирает и публикует проект при push в `main`. В Settings → Pages выберите GitHub Actions.

## Изображения
PNG-файлы скинов находятся в `public/images/`. Используйте изображения, на которые у вас есть права.
